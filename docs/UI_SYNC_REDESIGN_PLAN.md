## 1. 目標與範圍

本次目標是讓 GUI 與 Chrome 擴充功能擁有一致的視覺、共用的模型與服務清單，以及能反映實際執行狀態的操作流程。

- GUI 參考使用者提供的側欄、藍色主色與卡片風格，支援淺色、深色、跟隨系統。
- 重整擴充功能的模型選單、Target language、桌面預設與同步控制，減少常用操作中的資訊干擾。
- STT、GGUF、Ollama 與雲端 API profiles 由後端統一管理；GUI 是主要管理入口，擴充功能負責選用。
- 修正就緒狀態、失敗提示、設定生效時機、離線處理與分頁狀態呈現。
- 保留既有模型檔案、API profiles、語言輸入與正在執行的擷取設定。

本次不包含安裝包製作、STT 核心替換、新增研究候選模型，以及完整多 GPU／多語言品質 benchmark。這些仍依既有專案記憶另行追蹤。

## 2. 設計與資料所有權

| 資料 | 權威來源 | GUI 職責 | 擴充功能職責 |
|---|---|---|---|
| STT／翻譯模型目錄、下載及可用狀態 | 後端共用模型目錄 | 下載、匯入、管理與查看狀態 | 取得清單、選擇可用模型 |
| API／Ollama profiles 與憑證 | 後端設定儲存層 | 新增、編輯、測試、移除 | 依穩定 ID 選用，不另存可編輯副本 |
| 桌面預設模型、目標語言與翻譯行為 | 後端共用設定 | 編輯預設 | 明確選擇沿用或本分頁覆寫 |
| 分頁目前使用的設定 | 該次擷取的設定快照 | 顯示服務占用摘要 | 顯示目前設定與下次擷取設定 |
| 後端／模型執行狀態 | 後端執行狀態；分頁生命週期由擴充功能補充 | 顯示服務就緒、載入、錯誤 | 顯示連線、擷取、翻譯及分頁狀態 |
| 佈景與字幕外觀 | 介面偏好 | 儲存 GUI 偏好 | 儲存擴充功能與字幕偏好 |

實作遵循下列界線：

1. 清單共用不代表強制所有分頁共用目標語言；同一翻譯服務／模型可以服務不同語言的分頁。
2. 同一後端仍只允許一個翻譯服務／模型被使用；切換服務時不得偷偷停止其他分頁或改用其他模型。None 僅做辨識，可以共存。
3. 下載模型、取得目錄或儲存 profile 都不啟動 GPU 推論。最後一個翻譯使用者離開後，仍須回收受管理的程序。
4. 語言與模型保持開放集合。NLLB 等特殊協定保留相容層，不把舊 profile 改成語意不同的通用 LLM 設定。
5. 目錄只提供選用所需的名稱、ID、能力與狀態，不向擴充功能散布 API key 或本機模型路徑。
6. 共用設定的寫入應經一致的儲存邏輯，包含原子寫入與版本衝突處理，避免 GUI 保存舊快照覆蓋剛遷移的資料。
7. 佈景沿用同一組設計規則；GUI 與擴充功能各自記住 Light／Dark／System 選擇，後端離線時也能切換。

## 5. 工作清單與驗收條件

### A. 契約與基準

- [x] **A-01 共用目錄契約**：定義服務端識別、協定版本、目錄 revision、穩定 ID、STT／翻譯項目、預設值、可用狀態與服務占用摘要。確定舊擴充功能／舊後端的相容與升級提示。
- [x] **A-02 模型可用性**：區分已安裝、下載中、未下載、檔案遺失、相容性不足、已從選單移除。定義 GUI 自訂 STT 模型的 ID 與後端路徑解析，不再由擴充功能寫死可用模型。
- [x] **A-03 設定生效規則**：逐項列出設定所有權、沿用／覆寫、保存位置、生效時機與 active capture 快照策略；釐清 GUI 原有下載選項與新的 STT 預設欄位。
- [x] **A-04 視覺基準**：定義淺暗色語意色、字級、間距、圓角、圖示與主要／次要／危險動作樣式；完成 GUI Server 頁和 Popup 的兩種佈景草稿，包含離線與錯誤狀態。

驗收：契約寫入本文件或相鄰設計文件；能以範例說清楚 GUI 新增服務、擴充功能更新、離線、跨分頁覆寫、舊版本連線各會發生什麼事。草稿採用原有技術棧可實作的元件，不依賴圖片中不存在的功能。

### B. 統一清單、自動同步與遷移

- [x] **B-01 後端目錄與設定儲存**：提供共同 STT／翻譯清單；GUI 的下載、匯入、移除與 profile 保存能更新 revision。API profiles 與 Ollama 保留各自 adapter；可列出有問題的設定及原因，避免無提示消失。
- [x] **B-02 自動同步與離線快取**：擴充功能開啟、重新連線、切回設定畫面時更新；畫面開啟期間接收變更或採有界輪詢。保留上次成功清單、最後同步時間與選擇，離線時標示過期；按後端識別分隔快取，避免切換 URL 後錯用另一台的項目。
- [x] **B-03 舊 profiles 遷移**：加入可重試、可去重的匯入流程，處理既有名稱、引擎、model、URL、API 類型、endpoint 補全行為、憑證與選中 ID；保留 NLLB 等相容資訊。同名不同設定不自動覆寫。收到後端保存確認後，才切換為後端 ID。
- [ ] **B-04 防止兩份設定互相覆蓋**：遷移期間 GUI 與擴充功能的寫入經相同儲存規則；完成後擴充功能不再建立獨立服務副本。保留受控備份與回退方式，失敗時可恢復原有選擇，不把憑證寫進一般目錄快取或日誌。

驗收：

- 本機連線正常、畫面持續開啟時，GUI 保存變更後目標在 3 秒內更新擴充功能；記錄實測時間，背景分頁節流另列限制。
- 取得清單不載入 STT／LLM、不下載模型、不影響執行中擷取。
- 重複遷移不增加重複項目；中斷重試、同名衝突、缺少憑證、舊 profile 不支援等情境都有明確結果。
- 臨時離線保留選擇與可辨識名稱，但不把過期清單標成已驗證可用；重新連線後能更新或明確說明項目已移除。

### C. 執行狀態與設定生效

- [x] **C-01 後端 readiness 與診斷**：以實際服務回應確認 Ready，區分 Stopped／Starting／Ready／Stopping／Error。就緒檢查識別本次服務實例，避免誤把占用同 port 的其他程序當成功。擷取實際失敗原因並提供日誌入口。
- [x] **C-02 啟動與下載解耦**：後端可在尚未下載模型時啟動並提供目錄。模型準備在使用者選定並開始擷取時驗證；未下載模型引導至 GUI 管理，不因瀏覽下載選項而阻擋 Server 啟動。
- [ ] **C-03 持續狀態與分頁快照**：擷取狀態獨立於目錄請求更新。訂閱背景／後端狀態，分開呈現連線、準備模型、擷取音訊、翻譯與錯誤。保留目前設定快照、下次選擇與服務占用資訊；Stop 在目錄逾時或載入中仍可操作。
- [x] **C-04 沿用預設與生效提示**：沿用時省略相應覆寫，由後端解析；自訂時才送出分頁值。新增未儲存提示，區分立即生效、下次擷取生效與需要重啟；不自動重啟或修改其他分頁的執行設定。

驗收：

- port 占用、依賴錯誤、程序提早退出與啟動逾時不會顯示 Ready；服務 Ready 與模型載入完成是不同狀態。
- 模型載入中、目錄逾時、後端斷線後，Popup 的狀態與 Start／Stop 可正確更新，不需要關掉重開。
- GUI 預設語言改為非 zh-TW 時，沿用設定的新擷取使用新預設；明確選 zh-CN、es-MX、粵語等值保持原意。
- 兩個分頁可使用同模型不同語言；切換到另一服務會顯示占用原因，既有字幕流程不受影響。

### D. GUI 改版

- [x] **D-01 視覺與導覽**：保留 PySide6，導入側欄與內容頁，統一 Server、STT models、Local translation、Translation services、進階調整與 Settings 的版面。加入 Light／Dark／System 與偏好保存，System 模式回應系統變更。
- [x] **D-02 Server 與服務狀態**：以連線卡片、主要控制列、狀態摘要呈現；詳細錯誤可展開，提供複製連線位址與開啟日誌。狀態來源使用 C 階段契約，不以裝飾文字代替。
- [x] **D-03 管理頁與保存流程**：模型顯示下載／已安裝／可選／使用中等狀態；服務提供新增、編輯、測試及移除。按服務類型呈現相關欄位，vLLM helper 與進階參數收合；顯示未儲存與生效提示，Reset 說明影響範圍。
- [ ] **D-04 尺寸、鍵盤與既有行為**：處理 900×640、較大視窗與 Windows 125%／150% 縮放，頁面可捲動、按鈕不裁切。確認 Tab 焦點、停用狀態、托盤、關閉與重啟行為。

驗收：所有主要頁面在兩種佈景都有實際 Qt 截圖；切換與重開可保留偏好。主要／次要／危險操作可辨識，下載取消、模型匯入與保存仍可用。檢視參考圖相似度以導覽、資訊層級與色彩為準，不要求逐像素複製。

### E. 擴充功能改版

- [x] **E-01 Popup 與 Options 分工**：Popup 聚焦連線、辨識、翻譯、語言與擷取；字幕外觀為次要區域，詳細偏好移至 Options。固定開始／停止控制，使用同一組淺暗色規則，支援 System 與偏好保存。
- [x] **E-02 共用選單與同步狀態**：移除獨立 profile 管理介面，顯示後端提供的模型與服務。Desktop default／None 作為系統選項，不提供 Delete。重新整理放在狀態列旁，補上同步中、離線、需升級、無可用模型與項目已移除狀態。
- [x] **E-03 語言與設定層級**：保留可自由輸入的建議清單，選單顯示友善名稱；輔助文字放下方或提示區，不與輸入並排擠壓。明確標示沿用／自訂、翻譯 partial 與字幕 partial 顯示的差別；不翻譯時收合相關設定。
- [ ] **E-04 執行狀態與一致性**：顯示本分頁目前使用的模型／語言、下次設定和其他分頁占用摘要。Options 與 Popup 在開啟期間同步偏好變更，斷線與載入錯誤及時更新，不因全域最近選擇冒充本分頁實際設定。

驗收：

- 在真正 380×560 Popup 尺寸與獨立 Options 頁驗證；最小尺寸、長模型名、自訂語言與錯誤文字不產生橫向溢出，停止按鈕保持可見。
- 不再出現刷新按鈕或整段語言說明塞在輸入框容器的版面。
- 鍵盤能辨認焦點並操作核心流程；文字對比、停用狀態與下拉元件適應淺暗色，減少動態效果偏好得到尊重。
- 既有 profiles 遷移完成前顯示遷移結果與可修復入口，不直接丟棄使用者資料。

### F. 整合驗收與交接
